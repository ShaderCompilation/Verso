# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities (for
example, in the local Wi-Fi transfer server, update signature verification, or
the Kindle launcher).

Instead, report them privately through
[GitHub Private Vulnerability Reporting](https://github.com/ShaderCompilation/Verso/security/advisories/new).

Include as much detail as you can: the Verso version, Kindle model/firmware (if
applicable), steps to reproduce, and any impact assessment.

## Supported versions

Verso is in early development (`v0.1`). Security fixes are applied to the latest
release on `master`.
